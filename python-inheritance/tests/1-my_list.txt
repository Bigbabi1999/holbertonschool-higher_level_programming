================================================================================================================================
MyList
================================================================================================================================

Import the MyList class:

    >>> MyList = __import__('1-my_list').MyList

Create a MyList:

    >>> my_list = MyList()

Add some integers:
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)

Print the original list:

    >>> print(my_list)
    [1, 4, 2, 3, 5]

Print the sorted version:

    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]

Check that the original list has not changed:

    >>> Print(my_list)
    [1, 4, 2, 3, 5]
